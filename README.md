# strixtechnical.com

Website for Strix Technical Services LLC, served by GitHub Pages.

- `index.html` is the whole site. `images/` holds the photos.
- `CNAME` points GitHub Pages at strixtechnical.com. Don't delete it.
- The request form posts to a Google Apps Script web app in the Strix Google Drive
  ("Strix Leads" sheet). Its URL is the `FORM_ENDPOINT` value near the bottom of `index.html`.
